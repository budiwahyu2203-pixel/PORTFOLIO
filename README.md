# Portfolio Website

Static corporate portfolio for Wahyu Budiyono. Bilingual English and Indonesian. No framework, no package install, no external tracking, no secrets.

## Files

- `index.html` - page structure and bilingual copy
- `styles.css` - corporate layout and responsive styles
- `script.js` - language toggle
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## Privacy

Published contact email: `budiwahyu2203@gmail.com`.

Not published: old email, phone numbers, full address, reference contacts, raw CV PDF, client data, trading methods, performance claims, and investment advice.

## Local preview

Open `index.html` in a browser, or run a local server from this folder:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

Repository: `https://github.com/budiwahyu2203-pixel/PORTFOLIO`.

Publishing source: `gh-pages` branch, root folder. GitHub Pages publishes a project site automatically when a `gh-pages` branch exists.

Expected public URL: `https://budiwahyu2203-pixel.github.io/PORTFOLIO/`.

The `main` branch keeps the same files as a readable source branch. Both branches use relative asset paths, so the site works from a subdirectory.

## Fiverr profile

Use the public URL in the Fiverr profile website field once the page loads successfully.

Before sharing, verify the language toggle, email link, desktop layout, mobile layout, and that no sensitive data appears in the rendered page.
